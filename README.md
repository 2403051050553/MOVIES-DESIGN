# Movie Design Clone

A static movie-catalog interface mockup built with HTML and CSS.

## Overview

A dark movie-browsing layout with category navigation, featured movie banners, and “New Releases” movie cards.

## Interface Highlights

- Navigation labels for Home, Movies, Series, Popular, and Trends
- Featured panels with artwork and Watch buttons
- Movie cards with titles, descriptions, and poster images
- CSS hover effects that reveal card details

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.

An internet connection is needed to load the Google Fonts and Font Awesome assets linked in the page.

> This is a front-end mockup; the Watch buttons are not connected to movie playback.
